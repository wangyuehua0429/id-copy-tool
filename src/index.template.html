使用教程

  1. 1
    选类型并添加

    左侧下拉选证件类型（如 身份证 / 荣誉证书），点 ＋ 添加 可建多张。

  2. 2
    上传图片

    点卡片上的 正面 / 背面 框上传对应图片；也支持拖入或粘贴。

  3. 3
    调整设置

    右侧可改水印文字 / 透明度、版式（一页多份 / 上下排列）、复印件感滤镜等。

  4. 4
    预览并导出

    中间查看实时 A4 效果，点 导出 PDF / PNG / JPG 下载，或用 系统打印 走真实打印机。

按 Esc 关闭
